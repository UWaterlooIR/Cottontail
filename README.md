# Annotative Indexing

A unified approach to indexing that currently supports inverted indices, links, graph structures, JSON, other structured text, dynamic indices, and transactions, with planned support for regular expressions and dense retrieval.

Charles L. A. Clarke. 2025. Annotative Indexing. *Information Retrieval Research* 1, 1 (2025), 109–136. https://doi.org/10.54195/irrj.19910

## Running the search stack

To build an index from JSONL, search it from the command line, serve it over HTTP,
or drive it with an LLM agent, follow the
**[search-stack run guide](docs/running-the-search-stack.md)** — the single,
copy-paste-runnable source for how to run these tools. It links out to the design
specs for detail.

Build, test, and toolchain prerequisites are in [`CLAUDE.md`](CLAUDE.md).
