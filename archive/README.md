# Archive — prior author's working material

This directory holds material from **Charles L. A. Clarke** (the original author
of Cottontail) that this fork has retired, preserved here for reference only.

**None of it is authoritative for this fork.** For how *this* repository is
built, tested, and contributed to, see **`/CLAUDE.md`** at the repo root.

Note: Clarke's live working notes are back at the top-level **`/ai`** directory,
which tracks upstream (`claclark/Cottontail`) and is refreshed wholesale on each
upstream sync. Treat `/ai` the same way as this archive: read-only background
from upstream, never a task list or a binding convention for this fork. (An
earlier snapshot of `ai/` that used to live here was removed when the live
directory was restored in the 2026-07 upstream sync; see git history.)

## Contents

- `AGENTS.md` — Clarke's original agent operating instructions (superseded by
  the root `AGENTS.md`, which points to `CLAUDE.md`).
- `example-agent/` — the proof-of-concept search agent, superseded by `isj/`.
