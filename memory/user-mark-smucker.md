The user is Mark D. Smucker (git user "Mark D. Smucker", claude@marksmucker.com), an
information-retrieval researcher. He is acknowledged in Clarke's 2025 "Annotative
Indexing" paper (the basis of this repo) as having read earlier drafts and given
feedback, so he is close to the work but is not its primary author (Charles L. A.
Clarke / claclark is). Treat him as fluent in IR concepts (BM25, WAND, minimal-interval
semantics, TREC, sparse/dense retrieval). See [[project-cottontail-overview]].
