## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The agentic-ISJ system specified in docs/agentic-isj-investigation-planner.md needs a place in the repo. This task creates the full directory skeleton as a **top-level** `isj/` project (NOT under examples/ — it is the primary system of the design doc and a real TREC RAG 2026 deliverable, not a demo), and stubs out only the **Analyst** agent as the first concrete module. Every other agent, engine module, fixture, and test is left for follow-on tasks.

The `isj_agent` package is an **installed (editable) package**: isj/pyproject.toml declares a build-system and package discovery, so `uv sync` installs it into the venv and `from isj_agent...` imports resolve regardless of cwd. This intentionally differs from examples/agent, which is a `package = false` pair of flat scripts.

Note on naming: the top-level project directory is `isj/` (short, unambiguous); the importable Python package inside it is `isj_agent/` (clearly distinct, no hyphen-vs-underscore confusion).

## What this task delivers

The items marked `← stubbed in this task` above. Specifically:

1. **README.md** — short pointer to docs/agentic-isj-investigation-planner.md, plus a how-to-run placeholder noting further detail follows as agents come online.
2. **pyproject.toml + uv.lock** — own uv project, Python >= 3.12, deps `pydantic` and `openai`, configured so `isj_agent` is an installed (editable) package (build-system + package discovery). The examples/agent lockfile is **not** shared.
3. **isj_agent/protocol/inp.py** — a `pydantic.BaseModel` stub with `model_config = ConfigDict(extra="allow")` and no declared fields. The detailed schema mirroring §2.1 (slots, closed-enum validators, required vs. optional split) is TBD and deferred to a follow-on task. The stub is sufficient for the Analyst type annotation and contract test.
4. **isj_agent/agents/analyst.py** — a stub `Analyst` class with the §4.1.1 contract: `__init__(self, prompt_path: Path)`; `analyze(self, question: str) -> INP` raises `NotImplementedError`. One instance can handle many questions.
5. **prompts/analyst.md** — first-draft Analyst prompt (the §4.1.1 job description translated into a model-facing prompt). Allowed to be incomplete; will be refined in the Analyst implementation task.
6. **Python package markers** — `__init__.py` in every package directory (isj_agent/, isj_agent/protocol/, isj_agent/agents/, isj_agent/engine/, tests/).
7. **.gitkeep placeholders** — every directory in the layout that would otherwise be empty. At this stage the only such directory is tests/fixtures/.
8. **tests/test_analyst.py** — a single contract-surface test that imports `Analyst`, asserts the input/output types, and asserts that `analyze()` raises `NotImplementedError`. Real behavioral tests come in the Analyst implementation task.

## What this task explicitly does NOT do

- Does not implement the Analyst behavior (no LLM call, no prompt rendering, no actual INP production).
- Does not define the INP schema in detail (deferred to a follow-on task).
- Does not stub Cartographer / Strategist / Query Author / Judge / Tactician / Critic / Writer.
- Does not stub Searcher / Session Controller / Bookkeeper / Compiler / Validator.
- Does not stub the orchestrator or the CLI.
- Does not create per-topic fixtures.
- Does not touch examples/ (the existing examples/agent demo is unrelated and left untouched).
